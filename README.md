# FixTrack 🛠️
> **Stop living with it. Seen. Owned. Fixed.**

FixTrack is a modern, transparent facility maintenance and issue tracking platform designed specifically for campus living and workspaces. It streamlines reporting, prevents duplicate tickets, and provides real-time SLA tracking for facility managers.

## ✨ Key Features

* **Rapid Issue Intake:** Report campus issues in under 60 seconds with drag-and-drop diagnostic photo uploads, urgency tier selection, and QR auto-detected campus routing.
* **Real-time Duplicate Guard:** Similarity verification automatically detects and suggests nearby active reports. Residents can upvote existing issues ("I'm affected too") to raise priority without creating campus noise.
* **Live Issue Board:** A transparent, community-driven dashboard displaying real-time maintenance tickets with color-coded status badges, priority tags, and estimated resolution timelines.
* **Smart Dispatch & Prioritisation:** A Kanban-style control center for facility managers to allocate technical specialists, balance staff workloads, and monitor SLA compliance.
* **Resident Verification Loop:** Complete procedural transparency. Technicians submit before/after photo evidence and an itemized parts list for residents to verify and officially close the ticket.
* **Maintenance Analytics:** A high-level dashboard providing operational oversight, including issue distribution, overdue escalations, and real-time staff capacity metrics.
